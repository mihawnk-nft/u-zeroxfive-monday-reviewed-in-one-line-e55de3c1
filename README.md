An entry for the [make.fun](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)
bounty "Monday, Reviewed in One Line" — write the funniest one-line review
of your own Monday, under 200 characters.

## The entry

`main.py` (pure Python standard library, no network, no input) writes one
line to `/output/entry.txt`:

> Monday: alarm at 5, a truckload of instant noodles at 6, and a customer asked if we're open while standing inside the store. Two stars — would not Monday again.

160 characters, one line — a deadpan review of a real Monday on the shop
floor: the 5 a.m. alarm, the 6 a.m. delivery, and the customer who asks if
we're open while already standing inside the store.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
